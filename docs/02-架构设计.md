## 2. 技术栈与设计原则

| 项 | 决策 | 理由 |
|---|---|---|
| C++ 标准 | **C++17** | VTK9.6/ITK5.4 均要求 C++17 |
| DICOM 头/分组 | **DCMTK** | 已编译 DCMTK 3.7；读 SeriesNumber/InstanceNumber/方向，做序列分组 |
| DICOM 像素读取 | **ITK + GDCMImageIO** | spacing/origin/direction 自动解析，`ImageToVTKImageFilter` 转 vtkImageData（3d-xmake 成熟链路） |
| MPR 切片 | **vtkResliceImageViewer 子类**(内部 `vtkImageReslice`) | 复用 3d-xmake 的 `MyResliceImageViewer` 方案，三视图共享 `vtkResliceCursor` |
| 体绘制 | **vtkSmartVolumeMapper** | GPU ray cast + CPU 回退，VTK9 推荐 |
| 线程 | **QThread + 信号槽** | Qt6 原生；进度经 `progress(int)` 信号上报 `QProgressDialog` |
| 序列选择 UI | **QListView + QAbstractListModel + QItemDelegate** | 3dpre ThumbNailer 模式，自绘缩略图，优于 QListWidget |

**设计原则**：
1. 数据与渲染解耦：数据模型(`core/`) 不依赖任何 VTK 渲染细节，仅暴露 `vtkImageData*` 与元数据。
2. 视图即组件：四个视图是独立的 QWidget，由 `ViewManager` 编排联动。
3. 解析与加载分离：头信息解析(同步、快) 与像素加载(异步、慢) 分两个阶段。
4. 相对路径 + 环境变量：延续 01 文档约定，不硬编码绝对路径。
5. **资源与代码分离**：中文文案/ToolTip/错误提示/路径等常量集中到 `resources/`，不散落业务代码（见 §3.1）。
6. **小类 + 详细注释**：每个类单一职责、代码量克制；命名通俗易懂；关键处写中文注释说明"为什么"。
7. **设计模式驱动**：类设计显式应用设计模式（见 §8 的"设计模式"列），便于理解与扩展。

**依赖方向（单向，自底向上）**：

```
common → dicom → core → view → ui → app
                     └→ core ←┘
```

- `dicom` 依赖 `common`；`core` 依赖 `dicom`(仅类型)；`view` 依赖 `core`(取 vtkImageData)；
  `ui` 依赖 `core`(取序列/缩略图)；`app` 依赖所有层做编排。
- **`core` 不依赖 `view`**，数据模型不含渲染管线；渲染管线在 `view` 内按需构建。

struct DcmImage {

## 5. 三维重建原理

### 5.1 DICOM 加载管线（DCMTK 分组 + ITK 读像素）

```
DicomScanner::scan(path)
  │  递归枚举文件, 剔除 DICOMDIR
  │  DCMTK DcmFileFormat 读 SeriesNumber / InstanceNumber / ImagePositionPatient(Z)
  │  按 SeriesNumber 分组 → 按 InstanceNumber 排序 → Z 递减则 reverse(方向校正)
  ▼
QList<DcmSeries>          // 每序列含文件列表 + 元数据
  │
  │ ThumbnailCreator::make(series)   // 取中间帧, DCMTK DicomImage → QImage
  ▼
DcmSeries::thumbnail
  │
  │ 用户选中某序列 → VolumeLoader::load(series)
  ▼
itk::Image<short,3>       // itk::ImageSeriesReader + itk::GDCMImageIO
  │ itk::ImageToVTKImageFilter<itk::Image<short,3>>
  ▼
vtkImageData              // spacing/origin/direction 由 GDCM 自动解析
  │
  ▼
Volume(体数据)            // 供 MPR 与体绘制共用
```

> 关键：**头解析(分组/缩略图)用 DCMTK，像素读取用 ITK GDCM**。
> 这是 3d-xmake 主程序的实际链路，兼顾 DCMTK 分组强项与 ITK 像素解析(spacing/origin 自动)强项。

### 5.2 MPR 三视图（矢状/冠状/横断）

采用 **`vtkResliceImageViewer` 框架**（3d-xmake `MyResliceImageViewer` 方案），其内部即 `vtkImageReslice`：

```
ResliceViewer : vtkResliceImageViewer
  ├─ WindowLevel = vtkImageMapToWindowLevelColors   (窗宽窗位)
  ├─ ColorMap    = vtkImageMapToColors              (LUT, 自研扩展点)
  └─ resliceCursor                                  (vtkResliceCursor)
        └─ 内部 vtkImageReslice 完成斜切重采样
```

**三视图联动核心**：三个 `SliceView` 的 viewer **共享同一个 `vtkResliceCursor` 对象**，
光标中心/轴向全局唯一，十字线自动同步。

```cpp
// ViewManager 初始化三视图
sliceView[0]->viewer()->SetResliceCursor(cursor);      // 矢状
sliceView[1]->viewer()->SetResliceCursor(cursor);      // 冠状
sliceView[2]->viewer()->SetResliceCursor(cursor);      // 横断
// 方向
sliceView[i]->setOrientation(i);  // viewer->SetSliceOrientation(o)
```

**切片索引 ↔ 世界坐标换算**（`SliceView::synchronize`）：
```
world[orientation] = origin[orientation] + sliceIndex * spacing[orientation]
```

**事件分发**（`ViewManager` 内的 VTK callback，仿 3d-xmake `ViewManagerCallback`）：
- `vtkResliceCursorWidget::ResliceAxesChangedEvent` → 同步三个切片视图的几何
- 滚轮 → 单视图翻层 + 联动
- 窗宽窗位拖拽 → 三视图统一修改 WindowLevel

### 5.3 体绘制（三维视图）

```
Volume::imageData (vtkImageData)
  └─ vtkSmartVolumeMapper::SetInputData(img); SetBlendModeToComposite()
  └─ vtkVolumeProperty
       ├─ vtkColorTransferFunction   颜色(骨窗 RGB 关键点)
       ├─ vtkPiecewiseFunction       标量不透明度
       ├─ SetInterpolationTypeToLinear(); ShadeOn(); SetAmbient/Diffuse/Specular
  └─ vtkVolume::SetMapper(mapper); SetProperty(prop)
  └─ renderer->AddViewProp(volume)
```

**传递函数预设**（3d-xmake 的骨窗/软组织/肌肉三套，关键点参考其 `ImageDataNode::setRenderMode`）：
- `Preset::Bone`     骨窗：-1024~3060 HU 多段 RGB + 不透明度
- `Preset::SoftTissue` 软组织窗
- `Preset::Muscle`   肌肉窗

### 5.4 四视图布局与联动

```
┌──────────────┬──────────────┐
│  矢状面       │  冠状面       │   SliceView × 3 (vtkResliceImageViewer)
│  (Sagittal)  │  (Coronal)   │
├──────────────┼──────────────┤
│  横断面       │  三维体绘制   │   SliceView(横断) + VolumeView
│  (Axial)     │  (Volume)    │
└──────────────┴──────────────┘
```

- 四个视图挂载 `QVTKOpenGLNativeWidget`（VTK9 替代已移除的 `QVTKWidget`）。
- 三维视图用 `vtkInteractorStyleTrackballCamera` 旋转；切片视图用 `vtkInteractorStyleImage` 窗宽窗位/翻层。
- 十字线在三维视图中通过 `vtkImagePlaneWidget`(3 个正交平面) 可视化。

## 7. 线程模型

```
LoadThread : QThread
  ├─ 信号: progress(int percent), finished(结果), failed(QString err)
  ├─ 支持 requestCancel() 协作式取消
  └─ 两个用途(可复用):
       1. 扫描分组:  DicomScanner::scan
       2. 体数据加载: VolumeLoader::load

AppController
  ├─ 触发 → 启动 LoadThread → 弹 ProgressDialog
  └─ 收 progress → 更新进度条; 收 finished → 关弹窗 + 进入下一状态
```

> 扫描与加载都走同一 `LoadThread`（传入不同任务函数/类型），避免为每类任务建独立线程类。
> 取消采用标志位 + 循环内检查（DCMTK/ITK 深层解析难以即时中断，取消仅停止后续处理）。

**设计模式应用要点**（在类实现注释中标注）：

| 模式 | 具体应用 |
|---|---|
| 门面(Facade) | `DicomScanner`/`ThumbnailCreator`/`VolumeLoader` 对外提供"一句话完成复杂 DCMTK/ITK 操作"的简洁接口 |

| 模型视图(Model-View) | `SeriesListModel`+`SeriesThumbDelegate`+`QListView`，数据与显示分离 |

## 9. 图标与中文 ToolTip 规范

1. **图标资源**：统一放 `resources/icons/`，用 `resources/icons.qrc` 编译进可执行文件；
   图标来源可从 3d-xmake `images/` 或 Qt 标准图标库复制，命名 `action_xxx.svg/png`。
2. **文字常量**：所有中文文案取自 `resources/strings.h` 的 `AppStrings` 常量，不在代码里写字符串字面量。
3. **规范**：每个 `QAction` / `QToolButton` 必须同时设置图标 + 中文 ToolTip + 状态栏提示：
   ```cpp
   // 图标来自 .qrc, 文字来自 AppStrings 常量 —— 禁止散落的字符串字面量
   act->setIcon(QIcon(QStringLiteral(":/icons/action_open_ct.png")));
   act->setToolTip(AppStrings::kActionOpenCt);
   act->setStatusTip(AppStrings::kActionOpenCtStatus);
   ```
4. **必须覆盖的按钮**（及其中文 ToolTip，均定义于 `AppStrings`）：
   | 按钮 | ToolTip | 常量名 |
   |---|---|---|
   | 选择CT路径 | 选择 CT 序列目录 | `kActionOpenCt` |
   | 三维重建 | 对选中序列进行三维重建 | `kActionReconstruct` |
   | 窗宽窗位预设 | 切换骨窗/软组织/肌肉 | `kActionPreset` |
   | 重置视图 | 恢复默认视角与窗宽窗位 | `kActionReset` |

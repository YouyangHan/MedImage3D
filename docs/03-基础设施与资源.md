# 03 - 基础设施与资源

## 1. 本步目标

建立两大基础层，为后续 DICOM 解析、体数据加载、渲染等提供地基：

| 层 | 内容 | 作用 |
|---|---|---|
| `resources/` | `strings.h`(中文文案) + `paths.h`(路径常量) | 资源与代码分离，禁止魔法字符串 |
| `common/` | `Singleton` / `Logging` / `Settings` / `MathUtils` | 单例、日志、配置、数学工具 |

依赖关系：`common` 引用 `resources`（如 Settings 用 AppPaths 的组织名/应用名）。

## 2. 资源常量（resources/）

### 2.1 中文文案 [strings.h](../src/resources/strings.h)

集中管理所有中文 UI 文案（按钮文字 / ToolTip / 进度提示 / 错误消息），
采用 **C++17 `inline` 变量 + `QStringLiteral`**，多个编译单元共享同一实例。

```cpp
namespace AppStrings {
    // 工具栏按钮文字
    inline const QString kActionOpenCt      = QStringLiteral("选择 CT 序列目录");
    inline const QString kActionReconstruct = QStringLiteral("三维重建");
    inline const QString kActionPreset      = QStringLiteral("窗宽窗位预设");
    inline const QString kActionReset       = QStringLiteral("重置视图");
    // 进度提示
    inline const QString kProgressScan = QStringLiteral("正在扫描 DICOM 序列…");
    inline const QString kProgressLoad = QStringLiteral("正在重建三维体数据…");
    // 错误提示
    inline const QString kErrNoDicomFiles = QStringLiteral("所选目录中没有找到 DICOM 文件");
}
```

**要点**：业务代码引用 `AppStrings::kXxx`，禁止散落字符串字面量；后续国际化只需改此处。

## 3. 单例模板 [Singleton.h](../src/common/Singleton.h)

**设计模式：Singleton（Meyers 单例）**。利用 C++11 起局部静态变量线程安全的特性，
无需手动加锁。

```cpp
template <typename T>
class Singleton {
public:
    static T& instance() {
        static T s_instance;   // 首次调用时构造, 线程安全
        return s_instance;
    }
protected:
    Singleton() = default;
    Singleton(const Singleton&) = delete;            // 禁止拷贝
    Singleton& operator=(const Singleton&) = delete; // 禁止赋值
};
```

用法：`class Foo : public Singleton<Foo>`，再 `friend class Singleton<Foo>` 开放私有构造，
通过 `Foo::instance()` 获取唯一实例。

## 4. 日志 [Logging.h](../src/common/Logging.h) + [Logging.cpp](../src/common/Logging.cpp)

**基于 Qt `QLoggingCategory`**，按模块划分类别，提供便捷宏，不引入第三方日志库。

[Logging.h](../src/common/Logging.h) 声明类别 + 宏：

```cpp
Q_DECLARE_LOGGING_CATEGORY(lcApp)      // 应用/工作流
Q_DECLARE_LOGGING_CATEGORY(lcDicom)    // DICOM 解析
Q_DECLARE_LOGGING_CATEGORY(lcRender)   // 渲染/视图

#define LOG_INFO(cat, ...)  qCInfo(cat).noquote() << __VA_ARGS__
#define LOG_DEBUG(cat, ...) qCDebug(cat).noquote() << __VA_ARGS__
#define LOG_ERROR(cat, ...) qCCritical(cat).noquote() << __VA_ARGS__
```

[Logging.cpp](../src/common/Logging.cpp) 定义类别：

```cpp
Q_LOGGING_CATEGORY(lcApp, "app")
Q_LOGGING_CATEGORY(lcDicom, "dicom")
Q_LOGGING_CATEGORY(lcRender, "render")
```

调用示例：`LOG_INFO(lcApp, "应用启动: " << AppStrings::kAppDisplayName);`
运行时可用 `QT_LOGGING_RULES="dicom.debug=true"` 按类别过滤。

## 5. 配置 [Settings.h](../src/common/Settings.h) + [Settings.cpp](../src/common/Settings.cpp)

**设计模式：门面(Facade) + 单例(Singleton)**。封装 `QSettings`，集中管理 key 与默认值。

```cpp
class Settings : public Singleton<Settings> {
    friend class Singleton<Settings>;
public:
    QString lastDirectory() const;                 // 最近打开的 DICOM 目录
    void setLastDirectory(const QString& dir);
    bool rememberLastDirectory() const;            // 是否记住上次目录(默认 true)
    void setRememberLastDirectory(bool remember);
private:
    Settings();
    QSettings m_settings;
};
```

构造时用 `QSettings::IniFormat + UserScope + AppPaths::kOrgName/kAppName`（[Settings.cpp](../src/common/Settings.cpp)），
配置文件由 Qt 自动定位到用户目录，不硬编码路径。配置 key 常量仅在本 `.cpp` 内
（匿名命名空间），业务代码只通过接口访问，体现门面封装。

## 6. 数学工具 [MathUtils.h](../src/common/MathUtils.h)

**纯静态函数集合**（无状态，命名空间内聚，模板 + `constexpr` 编译期可用）：

```cpp
namespace MathUtils {
    constexpr double kPi = 3.14159265358979323846;

    template <typename T>
    constexpr T clamp(T value, T lo, T hi) { return std::clamp(value, lo, hi); }

    template <typename T>
    constexpr bool inRange(T value, T lo, T hi) { return value >= lo && value <= hi; }

    constexpr double degToRad(double deg) { return deg * kPi / 180.0; }
    inline long roundToLong(double v) { return static_cast<long>(std::lround(v)); }
}
```

> 纯头文件，随用随实例化；第 2 步 `DicomScanner` 会用到 `clamp`/`roundToLong`。

## 7. 集成验证 [main.cpp](../src/main.cpp)

在入口接入基础设施，验证各层可编译、可链接、可运行：

```cpp
#include "common/Logging.h"
#include "common/Settings.h"
#include "resources/paths.h"
#include "resources/strings.h"

int main(int argc, char* argv[]) {
    QSurfaceFormat::setDefaultFormat(QVTKOpenGLNativeWidget::defaultFormat());
    QApplication app(argc, argv);
    QApplication::setApplicationName(AppPaths::kAppName);
    QApplication::setOrganizationName(AppPaths::kOrgName);

    LOG_INFO(lcApp, "应用启动: " << AppStrings::kAppDisplayName);
    LOG_DEBUG(lcApp, "上次打开目录: " << Settings::instance().lastDirectory());

    MainWindow w; w.resize(1280, 800); w.show();
    return app.exec();
}
```

**验证结果**：编译 exit 0（新增 `Logging.cpp`/`Settings.cpp` 正常编译），运行时进程存活
（Logging + Settings + AppStrings 均正常）。

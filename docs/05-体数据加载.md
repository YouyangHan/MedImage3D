## 2. 数据流

```
用户点「三维重建」(SeriesInfo)
  │  LoadThread::run()            (后台线程)
  │    VolumeLoader::load(filePaths)
  │      itk::ImageSeriesReader + itk::GDCMImageIO   读像素
  │      itk::ImageToVTKImageFilter                   桥接 VTK
  ▼
Volume(vtkImageData + spacing/origin/dimensions)
  │  emit loadFinished(volume)    (队列连接, 跨线程)
  ▼
MainWindow::onLoadFinished -> DataRepository::setCurrentVolume(volume)
```

## 3. 体数据 Volume（值对象）

[core/Volume.h](../src/core/Volume.h) —— 纯数据载体，无业务逻辑：

```cpp
class Volume {
public:
    vtkSmartPointer<vtkImageData> imageData;          // 体数据(short, 3D)
    std::array<double,3> spacing {1,1,1};             // 体素间距(mm)
    std::array<double,3> origin  {0,0,0};
    std::array<int,3>    dimensions {0,0,0};
    bool isValid() const { return imageData != nullptr; }
};
Q_DECLARE_METATYPE(Volume)   // 跨线程队列连接传递用
```

**跨线程安全**：VTK 9 的 `vtkObjectBase::ReferenceCount` 是 `std::atomic<int32_t>`
（见 `ThirdParty/VTK/include/vtk-9.6/vtkObjectBase.h:275`），因此
`vtkSmartPointer` 的引用计数在加载线程与主线程间拷贝是线程安全的。

## 4. 数据仓库 DataRepository

[core/DataRepository.h](../src/core/DataRepository.h) —— **Singleton + Repository**：

```cpp
class DataRepository : public Singleton<DataRepository> {
    friend class Singleton<DataRepository>;
public:
    const Volume& currentVolume() const { return m_volume; }
    void setCurrentVolume(Volume volume) { m_volume = std::move(volume); }
    bool hasVolume() const { return m_volume.isValid(); }
    void reset() { m_volume.reset(); }
private:
    DataRepository() = default;
    Volume m_volume;
};
```

## 5. 体数据加载 VolumeLoader（Facade）

[dicom/VolumeLoader.cpp](../src/dicom/VolumeLoader.cpp) 封装整条 ITK 管线：

```cpp
Volume VolumeLoader::load(const QStringList& filePaths, ProgressCallback progress)
{
    using PixelType = signed short;                 // CT HU 值可负
    using ImageType = itk::Image<PixelType, 3>;
    using ReaderType = itk::ImageSeriesReader<ImageType>;
    using BridgeType = itk::ImageToVTKImageFilter<ImageType>;

    auto reader = ReaderType::New();
    reader->SetImageIO(itk::GDCMImageIO::New());    // GDCM 解析像素+spacing/origin
    // QStringList -> std::vector<std::string>
    reader->SetFileNames(names);
    reader->Update();

    auto bridge = BridgeType::New();                // ITK -> VTK
    bridge->SetInput(reader->GetOutput());
    bridge->Update();
    volume.imageData = bridge->GetOutput();
    // 提取 spacing / origin / dimensions
    ...
}
```

**关键分工**（延续第 2 步）：头解析用 DCMTK，**像素读取用 ITK GDCM**（自动解析
spacing/origin，并应用 Rescale 得到 HU 值）。

**进度观察者** [VolumeLoader.cpp](../src/dicom/VolumeLoader.cpp) 内定义
`LoadProgressCommand : itk::Command`，把 `ImageSeriesReader` 的 `ProgressEvent`
转发为 `0..1` 回调（通过 `itk::ProcessObject::GetProgress()`），驱动加载进度条。

## 6. 后台加载 LoadThread

[dicom/LoadThread.h](../src/dicom/LoadThread.h)：

```cpp
class LoadThread : public QThread {
    Q_OBJECT
signals:
    void progressChanged(double progress);         // 0..1
    void loadFinished(const Volume& volume);
protected:
    void run() override {
        const Volume volume = VolumeLoader::load(m_filePaths,
            [this](double p){ emit progressChanged(p); });
        emit loadFinished(volume);
    }
};
```

## 7. 主窗口接线

[MainWindow.cpp](../src/MainWindow.cpp)：

1. `onReconstructRequested(series)`：收到面板信号，调用 `startLoad`；
2. `startLoad()`：弹加载进度框（0..100），`new LoadThread(series.filePaths)`；
3. `onLoadFinished(volume)`：关进度框，失败弹警告，成功 `DataRepository::setCurrentVolume`
   并在状态栏显示体数据尺寸/间距。

元类型注册在 [main.cpp](../src/main.cpp)：


## 10. 设计模式小结

| 模式 | 应用 |
|---|---|
| 门面(Facade) | `VolumeLoader` 封装 ITK GDCM 整条读取管线 |
| 单例(Singleton) | `DataRepository` 全局唯一仓库 |
| 仓库(Repository) | `DataRepository` 集中管理当前数据 |
| 值对象(Value Object) | `Volume` 无逻辑的数据载体 |
| 线程模型 | `LoadThread`(QThread) + 队列连接跨线程传递 Volume |

## 2. 体绘制原理

```
Volume::imageData (vtkImageData)
  └─ vtkSmartVolumeMapper (GPU 光线投射 + CPU 回退) ::SetInputData; SetBlendModeToComposite
  └─ vtkVolumeProperty
       ├─ vtkColorTransferFunction   颜色(标量 -> RGB 关键点)
       ├─ vtkPiecewiseFunction       标量不透明度(标量 -> 0..1 关键点)
       └─ ShadeOn + Ambient/Diffuse  光照
  └─ vtkVolume ::SetMapper(mapper); SetProperty(prop)
  └─ renderer->AddVolume(volume)
```

交互用 `vtkInteractorStyleTrackballCamera`（轨迹球旋转/缩放/平移）。

## 3. 传递函数工厂 TransferFunctionFactory（Factory + Strategy）

[view/TransferFunctionFactory.cpp](../src/view/TransferFunctionFactory.cpp) ——
把三套预设封装成可替换策略，工厂方法按枚举创建：

```cpp
enum class TransferPreset { Bone, SoftTissue, Muscle };

vtkSmartPointer<vtkVolumeProperty> TransferFunctionFactory::createVolumeProperty(TransferPreset preset)
{
    vtkNew<vtkColorTransferFunction> color;
    vtkNew<vtkPiecewiseFunction> opacity;
    vtkNew<vtkVolumeProperty> prop;
    prop->SetColor(color);
    prop->SetScalarOpacity(opacity);
    prop->SetInterpolationTypeToLinear();
    switch (preset) {          // 策略分支
    case TransferPreset::Bone:       setupBone(color, opacity, prop);       break;
    case TransferPreset::SoftTissue: setupSoftTissue(color, opacity, prop); break;
    case TransferPreset::Muscle:     setupMuscle(color, opacity, prop);     break;
    }
    return prop;
}
```

**关键点数据**（参考 3d-xmake `ImageDataNode::setRenderMode`）：

| 预设 | 颜色关键点 (HU, RGB) | 不透明度关键点 | 光照 |
|---|---|---|---|
| 骨窗 Bone | (-3024,0,0,0)(-16,0.73,0.25,0.30)(641,0.90,0.82,0.56)(3071,1,1,1) | (-3024,0)(-16,0)(641,0.72)(3071,0.71) | Ambient 0.1 / Diffuse 0.9 |
| 软组织 SoftTissue | (0,0,0,0)(500,1,0.5,0.3)(1000,1,0.5,0.3)(1150,1,1,0.9) | (0,0)(500,0.15)(1000,0.15)(1150,0.85) | Ambient 0.4 / Diffuse 0.6 |
| 肌肉 Muscle | (-3024,0,0,0)(-155,.55,.25,.15)(217,.88,.60,.29)(420,1,.94,.95)(3071,.83,.66,1) | (-3024,0)(-155,0)(217,0.68)(420,0.83)(3071,0.80) | Ambient 0.1 / Diffuse 0.9 |

> 骨窗/肌肉额外设置 `SetScalarOpacityUnitDistance(0.8919)` 校正层间距对不透明度的影响。

**设计模式**：新增预设只需加枚举 + 工厂分支，调用侧无需改动（开闭原则）。

## 4. 体绘制视图 VolumeView

[view/VolumeView.cpp](../src/view/VolumeView.cpp)：

```cpp
VolumeView::VolumeView(QWidget* parent)
{
    m_vtkWidget = new QVTKOpenGLNativeWidget(this);
    m_renderWindow = vtkSmartPointer<vtkGenericOpenGLRenderWindow>::New();
    m_vtkWidget->setRenderWindow(m_renderWindow);
    m_renderer->SetBackground(0, 0, 0);
    m_renderWindow->AddRenderer(m_renderer);
    // 轨迹球交互
    m_vtkWidget->interactor()->SetInteractorStyle(
        vtkSmartPointer<vtkInteractorStyleTrackballCamera>::New());
    m_mapper->SetBlendModeToComposite();
    m_renderer->AddVolume(m_volume);
}

void VolumeView::setVolume(vtkImageData* image, TransferPreset preset)
{
    m_mapper->SetInputData(image);
    m_volume->SetProperty(TransferFunctionFactory::createVolumeProperty(preset));
    m_renderer->ResetCamera();
    m_vtkWidget->renderWindow()->Render();
}
```

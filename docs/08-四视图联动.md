```
┌──────────┬──────────┐
│ 横断面    │ 矢状面    │   SliceView × 3 (vtkResliceImageViewer)
│ (Axial)  │(Sagittal)│

│(Coronal) │ (Volume) │
```

四个视图由 `ViewManager` 统一编排，视图之间**不直接通信**（中介者模式）。

## 3. 联动机制

### 3.1 切片索引 ↔ 世界坐标换算

三视图联动核心是**同一个光标中心**对应三张切片。换算关系
（[ResliceViewer.cpp](../src/view/ResliceViewer.cpp)）：

```
world[axis] = origin[axis] + slice * spacing[axis]     // axis: 0=X,1=Y,2=Z
slice = round((world[axis] - origin[axis]) / spacing[axis])
```

方向常量 `GetSliceOrientation()`：`SLICE_ORIENTATION_YZ`(0)=X轴、
`XZ`(1)=Y轴、`XY`(2)=Z轴。

### 3.2 两个方向的同步

```cpp
// 光标中心变化 -> 三视图同步切片
void ResliceViewer::synchronizeFromCursor() {
    rc->GetCenter(c);
    int z = round((c[axis] - origin[axis]) / spacing[axis]);
    this->SetSlice(z);
}

// 本视图切片变化 -> 更新光标中心 -> 广播 ResliceAxesChangedEvent
void ResliceViewer::synchronizeToCursor() {
    c[axis] = origin[axis] + this->GetSlice() * spacing[axis];
    rc->SetCenter(c);
    this->GetResliceCursorWidget()->InvokeEvent(
        vtkResliceCursorWidget::ResliceAxesChangedEvent);
}
```

### 3.3 事件流（ViewManager 内回调）

```
拖动十字线 ──ResliceAxesChangedEvent──> onCursorChanged()
                                          └─ 三视图 synchronizeFromCursor + Render

滚轮翻层 ──SliceChangedEvent──> onSliceChanged(view)
                                  └─ view->synchronizeToCursor()
                                       └─ 触发 ResliceAxesChangedEvent -> 广播
```

回调类 `ViewManagerCallback : vtkCommand`（[ViewManager.cpp](../src/view/ViewManager.cpp)）
用 `clientData` 区分「光标回调」与「切片回调」（后者携带源视图指针）。

## 4. ViewManager（Mediator + Observer）

[view/ViewManager.cpp](../src/view/ViewManager.cpp)：

```cpp
void ViewManager::setupViews()
{
    m_cursor = vtkSmartPointer<vtkResliceCursor>::New();
    // 三个切片视图 + 一个体绘制视图，2x2 网格
    for (int i = 0; i < 3; ++i) {
        auto* sv = new SliceView(this);
        sv->setOrientation(orientations[i]);
        sv->setSharedCursor(m_cursor);
        // 观察十字线拖动 -> 同步三视图
        sv->viewer()->GetResliceCursorWidget()->AddObserver(
            vtkResliceCursorWidget::ResliceAxesChangedEvent, m_cursorCb);
        // 观察滚轮翻层 -> 更新光标中心
        sv->viewer()->AddObserver(vtkResliceImageViewer::SliceChangedEvent, sliceCb);
    }
}

void ViewManager::setVolume(const Volume& volume)
{
    m_cursor->SetImage(volume.imageData);
    m_cursor->SetCenter(volume.imageData->GetCenter());
    for (SliceView* sv : m_sliceViews) {
        sv->setVolume(volume.imageData);
        sv->setSharedCursor(m_cursor);
        sv->synchronizeFromCursor();
    }
    m_volumeView->setVolume(volume.imageData, TransferPreset::Bone);
}
```

## 7. 疑难问题排查（重要，反复踩坑的结论）

### 7.1 必须用 OBLIQUE(斜切)模式，不能用 AXIS_ALIGNED

`vtkResliceImageViewer` 默认 AXIS_ALIGNED(轴对齐)模式**会禁用十字线 widget**
(`ResliceCursorWidget->SetEnabled(0)`)，红蓝绿参考线不显示，且切片不随光标联动。

**解决**：`SetupInteractor` 之后切 `SetResliceModeToOblique()`（`SetEnabled` 需要 interactor，
过早切换会报 "The interactor must be set prior to enabling the widget"）。
见 [SliceView.cpp](../src/view/SliceView.cpp)。

### 7.2 三个切片视图显示同一张切片（平面法向未更新）

`vtkResliceImageViewer::SetSliceOrientation` 只改相机，**不更新 cursor algorithm 的平面法向**
(构造时设为默认 XY 后不再变)。三个视图共享光标，法向都停在 XY，导致显示同一张横断面。

**解决**：`setSliceOrientation` 里 `SetSliceOrientation` 后手动
`rep->GetCursorAlgorithm()->SetReslicePlaneNormal(orientation)`。
见 [ResliceViewer.cpp](../src/view/ResliceViewer.cpp)。

### 7.3 十字线不显示（QVTKOpenGLNativeWidget 兼容性）

`QVTKOpenGLNativeWidget` 用 `vtkGenericOpenGLRenderWindow`(framebuffer 渲染)，对
`vtkResliceCursorActor` 的线渲染有兼容性问题。即使数据/可见性/mapper 输入/颜色全正确，
十字线仍渲染不出来。**组合方案**：

1. `renderWindow->SetMultiSamples(0)` 禁用多重采样（线渲染异常）；
2. 十字线 property `SetRepresentationToWireframe()`（避免被图像遮挡）+ 显式红蓝绿颜色 + 加粗线宽；
3. `rep->SetRestrictPlaneToVolume(1)`（限制平面在体数据内）；
4. **`SetInputData` 之后**才 `GetResliceCursorWidget()->On()`（光标有图像后才能正确启用）。

参考：[VTK resliceCursorWidget compatibility with QT](https://stackoverflow.com/questions/72356679/vtk-reslicecursorwidget-compatibility-with-qt)

### 7.4 初始不显示图像（需滚轮才显示）

OBLIQUE 模式切片/十字线依赖 `Render`，但 `setVolume` 填充数据后无初始渲染。
**解决**：`ViewManager::setVolume` 里 `QTimer::singleShot(0, ...)` 延迟到视图 show 之后
显式渲染三视图 + 体绘制（[ViewManager.cpp](../src/view/ViewManager.cpp)）。

### 7.5 相机平行缩放未适配体数据

OBLIQUE 模式十字线/切片可能超出视口。**解决**：`setSliceOrientation` 和 `setVolume`
里 `ResetCamera()` + `SetParallelScale(体数据最大尺寸 * 0.55)`（参考 3d-xmake）。

## 2. 工作流状态机 AppController

[app/AppController.h](../src/app/AppController.h) —— 纯状态机（State 模式）：

```cpp
enum class WorkflowState { Idle, Scanning, SeriesSelect, Loading, FourView };

class AppController : public QObject {
    Q_OBJECT
public:
    WorkflowState state() const { return m_state; }
    void transitionTo(WorkflowState s);   // 相同状态忽略，否则广播 stateChanged
signals:
    void stateChanged(WorkflowState state);
};
```

工作流（docs/02 §1.2）：

```
Idle -> Scanning -> SeriesSelect -> Loading -> FourView
        (扫描)      (序列面板)     (加载)      (四视图)
```

## 3. 主窗口集成

[MainWindow.cpp](../src/MainWindow.cpp) 在工作流关键点驱动状态机：

| 触发点 | 状态 |
|---|---|
| `startScan` | `Scanning` |
| `onScanFinished`(有序列) | `SeriesSelect` |
| `onScanFinished`(空/取消) | `Idle` |
| `startLoad` | `Loading` |
| `onLoadFinished`(成功) | `FourView` |
| `onLoadFinished`(失败) | `SeriesSelect` |

`onStateChanged` 按状态启用/禁用工具栏动作：

```cpp
void MainWindow::onStateChanged(WorkflowState state)
{
    const bool busy = (state == Scanning || state == Loading);
    const bool fourView = (state == FourView);
    m_openCtAction->setEnabled(!busy);
    m_reconstructAction->setEnabled(fourView || state == SeriesSelect);
    m_presetAction->setEnabled(fourView);
    m_resetAction->setEnabled(fourView);
}
```

## 4. 工具栏（图标 + 中文 ToolTip）

[MainWindow::setupActions](../src/MainWindow.cpp) 四个动作，均设图标 + ToolTip + 状态栏提示：

| 动作 | 图标 | 行为 |
|---|---|---|
| 选择 CT 目录 | `action_open_ct.svg` | 选目录 + 扫描 |
| 三维重建 | `action_reconstruct.svg` | 切回序列面板 |
| 窗宽窗位预设 | `action_preset.svg` | 循环骨窗→软组织→肌肉 |
| 重置视图 | `action_reset.svg` | 重新加载当前体数据 |

```cpp
m_presetAction = new QAction(QIcon(AppPaths::kIconPreset), AppStrings::kActionPreset, this);
m_presetAction->setToolTip(AppStrings::kActionPreset);
m_presetAction->setStatusTip(AppStrings::kActionPresetStatus);
```

图标经 [resources/icons.qrc](../src/resources/icons.qrc) 打包，运行时 `QIcon(":/icons/xxx.svg")` 引用；
文案取自 `AppStrings`/`AppPaths` 常量（资源与代码分离）。

## 5. 设计模式小结

| 模式 | 应用 |
|---|---|
| 状态机(State) | `AppController` 枚举状态 + `transitionTo` |
| 组合(Composite) | `MainWindow` 组合面板/视图/控制器 |
| 观察者(Observer) | `stateChanged` 信号驱动 UI 更新 |
